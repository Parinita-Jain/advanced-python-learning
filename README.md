Setup
Clone the repository:
git clone YOUR_REPOSITORY_URL
cd advanced-python-learning
Create and activate the environment:
uv sync
Windows Command Prompt:
.venv\Scripts\activate.bat
Run Python programs:
python filename.py
Purpose
This repository contains small, independent, executable projects designed to reinforce Python programming concepts through practical implementation.
